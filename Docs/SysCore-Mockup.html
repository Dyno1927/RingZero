C / fundamentals / pointers

pointers

A pointer holds the address of an object. Declaring one does not allocate storage for the pointee — it must be initialized before it is dereferenced.

copyint x = 10;
int *p = &x;
*p = 20; // x is now 20

Pointer arithmetic is scaled by the pointee's size, not by bytes. Incrementing an int* moves it forward by sizeof(int), not by one byte.

Dereferencing an uninitialized or dangling pointer is undefined behavior, not a guaranteed crash.
